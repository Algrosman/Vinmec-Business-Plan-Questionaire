Evidence-backed prototype

Welcome

This version is designed to support structured planning workshops between Cleveland Clinic Connected and Vinmec stakeholders. It uses an embedded knowledge base derived from the pasted Can Gio and Vietnam market materials to generate more contextualized recommendations.

What this version adds

  • Source-backed knowledge base
  • Contradiction detection
  • Vietnam / Can Gio contextual logic
  • Evidence and citation display
  • Backend-ready research hooks

What it is ready for later

  • Live web search integration
  • Server-side evidence ingestion
  • Research task automation
  • Shared evidence library
  • Private deployment with backend APIs
